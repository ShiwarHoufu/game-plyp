# 碰了又碰 (PengPengQi)

![碰了又碰](assets/images/title.png)

**碰了又碰** 是一款双人在线物理碰撞对战网页游戏。玩家像拉弹弓一样拖拽自己的棋子并松手发射，用碰撞把对方的棋子全部撞出棋盘即可获胜。游戏支持**本地双人同屏**和**在线联机对战**，包含多种玩法模式、技能系统、乱斗模式、道具、皮肤商店与战绩排行等完整功能。

> 纯浏览器运行（HTML5 Canvas + 原生 JavaScript），无需安装客户端；服务端为 Node.js + Socket.io。

## 🎮 玩法模式

| 模式 | 本地 | 联网 | 人数 | 说明 |
|------|:----:|:----:|:----:|------|
| **经典模式** `classic` | ✅ | ✅ | 2 人 | 最纯粹的回合制弹射碰撞。开局可设置每方棋子数（2~5）与颜色 |
| **技能模式** `skill` | ✅ | ✅ | 2 人 | 在经典规则基础上，每颗棋子绑定 1 个技能，每方再选 1 个全局技能 |
| **乱斗（2 人）** `chaos` | ❌ | ✅ | 2 人 | 无回合限制的实时碰撞，能量与道具系统 |
| **乱斗（4 人）** `chaos4` | ❌ | ✅ | 4 人 | 四名玩家同场自由混战，最后存活者获胜 |

- **获胜条件**：先把对方所有棋子全部撞出棋盘的一方获胜。
- **可选地形**：可开关"生成地形"，每 3 回合在场上随机生成一段白色墙体（最多 8 段），增加变数。

### 乱斗模式的特色机制

乱斗（chaos / chaos4）不是回合制，而是服务端驱动的**实时物理混战**：

- ⚡ **能量系统**：每次弹射消耗 1 点能量，能量随时间自动恢复（2 人模式 4 秒 / 4 人模式 3.5 秒恢复 1 点，上限 3 点）。
- 📦 **道具系统**：场上每隔一段时间随机生成道具，拾取即可获得特殊效果（见[道具系统](#-道具系统乱斗模式)）。
- 🧱 **动态地形**：游戏中持续随机生成墙体，改变碰撞路径。
- 🛡️ **开局保护**：开局前 10 秒内出界的棋子会回到原位。

## 🕹️ 基本操作

| 操作 | 说明 |
|------|------|
| **单击** | 选中自己的棋子（被选中的棋子会出现白框提示） |
| **按住并拖拽** | 像拉弹弓一样蓄力，棋子跟随鼠标/手指移动 |
| **松开** | 发射棋子，撞击对方棋子 |
| **力度条** | 拖得越远，力度越大（界面下方有力度条分级显示） |

> 提示：只拖拽自己的棋子才会生效；闪现技能用键盘方向键调整位置。

游戏过程中还支持 **聊天**（💬 按钮，表情 + 快捷语 + 文字）。

## 🎯 技能系统

技能模式中每个棋子都会绑定一个技能。**开局前 4 个回合不能使用技能**，除"分身"和"超重"外，其余技能每局每个棋子限用一次。

### 棋子技能

| 技能 | 效果 |
|------|------|
| 🔥 **狂暴** frenzy | 最大弹射力度翻倍；飞出棋盘后还能复活 |
| 💠 **二连击** doubleStrike | 可以连续弹射两次 |
| 🟡 **闪现** blink | 发射前可在一定范围内用方向键移动棋子位置 |
| 🟣 **分身** clone | 在棋盘任意位置放置一个不能主动弹射的分身（存在 6 回合，可用 2 次） |
| 🟠 **超重** heavy | 质量与体积大幅增大（持续 6 回合），几乎撞不动 |
| ⚪ **无形** intangible | 在对方回合获得穿透效果，可穿过对方棋子（持续 4 回合） |

### 全局技能

每个玩家每局可选 1 个全局技能（影响场上**所有**棋子，双方不会同时生效）：

| 技能 | 效果 |
|------|------|
| 🟤 **虚弱** weakness | 场上所有棋子最大力度减半，持续 2 回合 |
| 🔵 **缩小** shrink | 场上所有棋子体积缩小，持续 2 回合 |

> 长对局规则：技能模式进行到第 20 回合时，会重置全场棋子的技能使用次数并清除进行中的技能效果。

## 📦 道具系统（乱斗模式）

道具在乱斗模式中随机生成，碰撞拾取后生效：

| 道具 | 效果 |
|------|------|
| 🟢 **快速恢复** quickRecovery | 能量恢复速度大幅提升（8 秒） |
| 🔵 **冰冻** freeze | 碰到它的棋子会被冰冻，短暂无法移动（5 秒） |
| 🟡 **富贵同享** sharedProsperity | 一段时间内自己出界的棋子会在随机位置复活 |
| 🔴 **我命由天** destiny | 立即随机删除场上一颗棋子 |
| ⚪ **隐身** invisibility | 一段时间内对方棋子隐身，只能看到轮廓 |
| 🩷 **浑然一体** oneBody | 一段时间内全场棋子统一为一体状态 |

## 🛠️ 技术栈

**前端**（纯原生，无打包器）
- HTML5 `<canvas>` 渲染 + 原生 JavaScript（`<script>` 全局类方式组织）
- CSS 动画、粒子特效
- Socket.io 客户端（CDN 引入）

**后端**
- Node.js + Express（静态资源与 REST API）
- Socket.io（实时联机，服务端权威物理模拟）
- MySQL（mysql2 连接池）· bcryptjs（密码哈希）· JWT（登录令牌）

    │   └── config/          # 数据库配置（从环境变量读取）
    └── .env.example         # 环境变量模板（复制为 .env 使用）

## 🏗️ 架构说明

采用三层结构，`shared/` 目录的代码同时在浏览器与 Node.js 中运行：

1. **客户端 `js/`**：负责渲染、本地操作与联网呈现。本地模式在浏览器内跑物理模拟；联网模式下则只渲染并播放服务端下发的对局。
2. **服务端 `server/src/`**：Node.js + Socket.io。管理房间/匹配、账号与商店数据，并在**联网对局中承担权威的物理模拟**。
3. **共享 `shared/`**：`GameConfig`（画布、棋子、技能、道具等全部数值）、`MessageTypes`（全部 Socket 消息常量）、`PhysicsEngine` / `SkillLogic` / `GameState` 等纯逻辑工具。

> 联网对局采用**服务端权威**：客户端发送拖拽/发射指令（`PLAYER_ACTION`）→ 服务端以 60FPS 运行物理并广播棋子坐标（`PIECE_POSITIONS`）→ 全部棋子停止后由服务端裁决胜负并切换回合。这样可避免玩家本地作弊或不同步。

## 🚀 本地运行

### 环境要求

- **Node.js ≥ 16**
- **MySQL**（仅账号 / 商店 / 战绩 / 在线奖励需要；只玩本地双人其实可以不启动数据库）

### 1. 初始化数据库

用仓库提供的脚本一键建库建表并写入种子商品数据（库名 `plyp_db`）：

```bash
mysql -u root -p < server/src/db/init.sql
```

### 2. 配置环境变量

```bash
cp server/.env.example server/.env
```

然后编辑 `server/.env`，把 `DB_USER` / `DB_PASSWORD` 改成你本地 MySQL 的账号密码。

### 3. 安装依赖并启动

```bash
npm run install:server   # 安装服务端依赖（等价于 cd server && npm install）
npm start                # 启动服务器
```

浏览器打开 **http://localhost:3000** 即可游玩。

**开发模式**（文件改动自动重启）：

```bash
npm run dev
```

## ⚙️ 环境变量配置

所有配置从 `server/.env` 读取，**不要**把真实 `.env` 提交到 Git（已被 `.gitignore` 排除），公共模板见 `server/.env.example`。

| 变量 | 必填 | 说明 |
|------|:----:|------|
| `DB_HOST` | ✅ | MySQL 地址，默认 `localhost` |
| `DB_PORT` | ✅ | MySQL 端口 |
| `DB_USER` | ✅ | 数据库用户名 |
| `DB_PASSWORD` | ✅ | 数据库密码 |
| `DB_NAME` | ✅ | 数据库名 |
| `DB_CONNECTION_LIMIT` | ❌ | 连接池上限，默认 `10` |
| `PORT` | ❌ | 服务器监听端口，默认 `3000` |
| `JWT_SECRET` | ❌ | JWT 签名密钥，生产环境务必改为随机长字符串 |
| `JWT_EXPIRES_IN` | ❌ | JWT 有效期，默认 `7d` |

## 🌐 在线对局流程

1. 进入游戏后，点右上角**登录**注册/登录账号（游客也可先玩本地模式）。
2. 主菜单点**联网对战**（未登录会自动弹出登录框）。
3. 在大厅可**创建房间**（选择经典 / 技能 / 乱斗2人 / 乱斗4人，可设置棋子数与地形）或**输入房间号 / 从列表加入**。
4. 房间内全员点**准备**后开局：
   - 经典 / 乱斗：先选择**棋子皮肤与拖尾效果**，确认后开战；
   - 技能：先轮流完成**技能选择**再开战。
5. 对局结束会记录战绩并发放金币奖励（胜方更多）。

## 账户系统

- 支持**注册 / 登录**、修改用户名与密码、查看历史战绩。
- **金币**：注册赠送 100，对局获胜/失败均可获得，用于在**商店**购买外观。
- **商店与背包**：出售多种**棋子皮肤**（黄盒、蓝盒、篮球、排球、霓虹流光等）与**拖尾特效**（火花、雪花、闪电等），买到即永久拥有，可在对局前装备。
